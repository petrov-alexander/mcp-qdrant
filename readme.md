# Настройка и запуск Qdrant
## Индексирование
### Клонирование репозитория
```bash
git clone git@github.com:qdrant/mcp-server-qdrant.git
```
### Запуск докера для индексирования
```bash
docker compose --env-file .index.env up -d
```
### Подключение MCP
```bash
claude mcp add --transport sse qdrant http://localhost:8000/sse
```
```bash
opencode mcp add qdrant --url http://localhost:8000/sse
```
### Создание индекса
Запусти claude и отправь команду:
```text
Используй инструмент qdrant-store, чтобы подробно проиндексировать все файлы репозитория
```
## Поиск
### Остановка docker
```bash
docker compose --env-file .index.env down
```
### Запуск docker для поиска
```bash
docker compose --env-file .find.env up -d
```
# Запросы поиска
## Для создания UML Классов
```text
Проанализируй найденный Python-код в базе данных. Построй подробную UML Class Diagram на языке Mermaid для модулей, отвечающих за [Название фичи, например: авторизацию пользователей]. Покажи методы классов, их аргументы, типы возвращаемых значений и связи (наследование --|>, композиция *--, ассоциация -->). Ответ запиши строго в файл mermaid. Никакого лишнего текста до и после блока.
```
## Для создания диаграммы последовательности
```text
Покажи по шагам, как в коде обрабатывается бизнес-процесс: [Например: Создание заказа и отправка email]. На основе исходного кода из базы данных построй Mermaid Sequence Diagram. Участниками (participants) должны быть конкретные Python-классы/сервисы (например, OrderController, PaymentService). Покажи стрелками вызовы методов и возвращаемые ответы. Ответ запиши строго в файл mermaid.
```
## Для объяснения логики
```text
Найди в базе данных места, где обрабатывается [Бизнес-логика расчета скидки]. Объясни простыми словами архитектурный подход: почему это реализовано именно так, какие паттерны проектирования использовались, и где в коде находятся ключевые точки ветвления (if/else).
```
